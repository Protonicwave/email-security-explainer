esx Email security explainer

Who can send email as your domain?

Enter the domain you send email from. esx reads its SPF and DMARC records from public DNS, audits them against RFC 7208 and RFC 7489, and marks each problem on the record itself.

Checking Reading its records from public DNS.

Each mark sits on the exact part of the record a finding rests on. Select one to read it.

What the audit found

Fixed rules from RFC 7208 (SPF) and RFC 7489 (DMARC), run as code. No language model decides what is wrong.

    Records are read from public DNS when you press Check domain, and nothing is stored. DKIM is not checked: finding a DKIM key needs a selector name that DNS does not reveal.
